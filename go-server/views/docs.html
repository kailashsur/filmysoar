API documentation.

A small, predictable REST API for browsing movies, categories, search results, static pages, and frontend settings.

Quick start

The API is public and returns JSON. Replace the host with your deployment domain.

curl https://your-domain.com/api/home
curl "https://your-domain.com/api/movies?page=1&limit=20"
Base URL: https://your-domain.com
Admin routes are private and are not part of this public API.

Homepage

GET /api/home

Returns trending movies, recent movies, categories, and pagination metadata. Optional page is normalized to a safe positive value.

Movies

GET /api/movies

Returns a paginated movie list. page defaults to 1; limit defaults to 20 and is capped at 100.

curl "https://your-domain.com/api/movies?page=2&limit=20"
GET /api/movies/:slug

Returns one movie by its URL slug.

GET /api/movies/trending

Returns the current trending movie list.

Categories

GET /api/categories

Returns categories with movie counts.

GET /api/categories/:slug

Returns one category and its paginated movies. Uses the same page and limit rules as movies.

Search

GET /api/search?q=term

Searches movie titles and metadata. Use page and limit for pagination.

curl "https://your-domain.com/api/search?q=action&page=1&limit=20"

Other endpoints

GET /api/static-pages/:slug

Returns a published static page by slug. Unpublished or missing pages return 404.

GET /api/astro-settings

Returns public Astro frontend settings as a key-value object.

Responses and errors

Successful responses use {"success":true,"data":...}. Errors use an HTTP status and {"success":false,"error":"..."}.

  • 200 request succeeded
  • 404 resource was not found
  • 500 server or database failure
